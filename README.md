//Employee Management System// 
📌 Project Overview

The Employee Management System is a menu-driven application developed using the C programming language. This project manages employee records and performs different operations using fundamental Data Structures and Algorithms (DSA).

The main objective of this project is to understand and implement Arrays, Linear Search, Binary Search, and Sorting in a real-world application.

🎯 Project Objectives
To store and manage employee information.
To add, update, and delete employee records.
To display employee details.
To generate department-wise employee reports.
To calculate total and average salaries.
To implement Linear Search and Binary Search.
To compare the performance of Linear Search and Binary Search.
🛠️ Technologies Used
Programming Language: C
Data Structure: Arrays and Structures
Algorithms: Linear Search, Binary Search, Sorting
Compiler: GCC
Platform: Windows / Linux
📚 Main DSA Concepts
Concept	Application
Arrays	Store employee records
Structures	Manage employee information
Linear Search	Search employees by name or department
Binary Search	Search employees by ID
Sorting	Sort employees by ID
⚙️ Project Modules
1. Employee Data Entry and Update
Add new employee details.
Modify existing employee details.
Delete employee records.
Store ID, Name, Department, Salary, and Joining Date.
2. Employee Display and Salary Report
Display all employee records.
Department-wise employee listing.
Calculate total salary.
Calculate average salary.
3. Linear Search Module
Search employees by name.
Search employees by department.
Perform searching on unsorted employee data.
4. Binary Search Module
Sort employees by Employee ID.
Search employees using Binary Search.
Compare Linear Search and Binary Search.
Display the number of comparisons performed by both algorithms.
